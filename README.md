# 🏛️ 场地借用管理系统 (Venue Rental System)

循人中学联课活动处的场地借用登记与公布系统。资料存在 Google 试算表「联课处场地系统-资料库」，程序是绑定在这份试算表上的 Google Apps Script 网页应用。

## 页面与网址

部署后的网页应用网址（`…/exec`）加上参数，对应四个页面：

| 网址参数 | 页面 | 谁能看 |
|---|---|---|
| （不加）或 `?page=admin` | 管理端：新增/修改/删除借用、特殊状态、公告 | 白名单内的管理员 |
| `?page=table` | 矩阵总表：场地 × 当月每一天，右侧有公告栏 | 学校网域账号 |
| `?page=view` | 日历视图：月 / 周 / 明细表 | 学校网域账号 |
| `?page=tv` | 电视看板：大讲堂、大礼堂、伯才堂本周时段表 | 学校网域账号 |

> 所有页面都要用**学校 Google 账号**登入才能打开（部署设定为「学校网域」）。

## 表格设定（试算表里要准备的东西）

### 《场地编号》工作表

前两栏**固定**是课室编号、场地名称（程序按位置读）；其余栏位按**表头文字**找，位置可以调整，但表头名称要一致。

| 栏位 | 用途 | 必填 |
|---|---|---|
| 课室编号（**A 栏**） | 场地编号，所有页面显示用 | ✅ |
| 场地名称（**B 栏**） | 场地的中文名称，可留空 | |
| 单位 | 借用单位的下拉选项。**行政单位**（编号以数字开头，例如 `01-校长室`）的格子手动上底色，各页面就会用这个颜色；学会团体（编号以字母开头）不上色 | ✅ |
| 管理员邮箱 | 管理端白名单 | ✅ |
| 管理员姓名 | 跟邮箱同一行填姓名。管理员新增借用时「填写人」留空，会自动带入「姓名 (email)」 | 建议 |
| 假期设定(月) / 开始(日期) / 结束(日期) | 每行一个月份的假期区间，例如 `01 \| 05 \| 14` = 每年 1 月 5 日至 14 日。见下方「假期」 | 选填 |

> 【状态】这一栏（考场 / 维修 / 不外借）目前程序**没有读取**，特殊状态的种类请到《特殊状态》表设定。

### 《特殊状态》工作表

第一次打开管理端时会自动建立。

- **A 栏**：状态种类，一行一个（维修、考试场地、不外借……），可以自由增加。格子底色就是这个状态在各页面的颜色。
- **C 栏以后**：系统自动写入的标记记录，**不要手动改**，要取消请用管理端。

### 《公告栏》工作表

第一次打开时会自动建立。公告内容在 **A2**（Markdown 语法），B2 是自动更新的时间。一般在管理端编辑就好，不用直接改这张表。

### 不要手动改的工作表

- `2026-01`、`2026-02` …：每个月一张，存借用记录，由系统自动建立。
- 《已删除记录(回收站)》：被删除、被修改前的旧记录，误删时可以从这里找回资料。
- 《操作日志》：每一次新增、修改、删除的记录。

## 管理员使用指南

### 新增借用

1. 用白名单里的账号打开管理端。
2. 勾选场地（可多选，可用搜寻框或楼栋按钮筛选）。
3. 填活动名称、选借用单位、选开始与结束时间（24 小时制）、选使用日期。
4. 「填写人」可以留空，系统会自动带入你的姓名和 email。
5. 按「提交记录」。成功后右下角会出现绿色提示。

**连续多天**：另外填「结束日期」。**只在每周某几天**：勾「🔁 只在特定星期几重复借用」，选星期几，并填结束日期。

提交时会自动检查：

- 结束时间要晚于开始时间；活动跨过午夜请拆成两笔。
- 结束日期不能早于开始日期。
- 同场地同时段已有人借用，会整批挡下并说明跟哪一笔冲突。
- 一次超过 50 笔会先问你确认，超过 200 笔会直接挡下（通常是年份打错）。
- 如果刚好有其他管理员也在写入，会请你等几秒再试。

### 查看、修改、删除

- 右侧「借用记录列表」预设只显示**近期**记录（3 个月前那个月起，含未来）。要找更早的记录，把「资料范围」切成「最近 12 个月起」或「全部记录」。
- 「编辑」：修改单笔记录（场地只能选一个）。修改后仍属于原本那一批，填写日期会变成修改当天，旧版本会存进回收站。
- 「🔗同批」：一键勾选同一次提交产生的所有记录，方便整批删除。
- 「删除」：单笔删除需要确认；勾选多笔后按「批量删除」，要输入笔数确认。删除的记录都在《已删除记录(回收站)》里。

### 特殊状态（维修、考试场地、不外借……）

1. 勾选场地、设定日期（可搭配结束日期、按星期重复）。
2. 在「🚧 特殊状态」区块勾选状态，按「🚧 提交特殊状态」。不用填活动名称、单位、时间。
3. 要取消时，到页面下方「🚧 特殊状态记录」点「取消状态」，或勾选多笔「批量取消」。

特殊状态只是标记，**不会阻挡**同一天的借用。

### 公告栏

管理端最下方「📢 矩阵总表公告栏」：左边写 Markdown，右边即时预览，按「💾 保存公告」。矩阵总表最多 5 分钟内会更新。

常用语法：`# 标题`、`**粗体**`、`*斜体*`、`- 条列`、`[文字](网址)`。Markdown 做不到的效果（例如彩色文字）可以直接写 HTML，例如 `<span style="color:#e67e22">橘色文字</span>`。

### 假期

在《场地编号》表的假期三栏设定，矩阵总表、日历、电视看板会把假期日期填成黄色底：

- 一行一个月份，例如 `05 | 22 | 31` = 每年 5 月 22 日至 31 日。
- 每年通用，换学年时照新校历修改。
- 跨月假期拆成两行（`08 | 28 | 31` 和 `09 | 01 | 05`）；同一个月两段假期就多加一行同月份；没有假期的月份把开始、结束留空。
- 假期当天有借用的格子仍然显示单位颜色。

## 电视看板

- 网址加 `?page=tv`，用浏览器全萤幕（Kiosk 模式）开在电视上。
- 电视上的浏览器要**保持登入一个学校 Google 账号**，建议用专门给电视的账号。
- 只显示大讲堂、大礼堂、伯才堂本周（周一至周日）07:00–22:00 的借用。
- 每 5 分钟自动更新资料；每 6 小时会整页重新载入一次（先确认网络和后端正常才重新载入）。不需要有人操作。

## 部署与更新

### 第一次部署

1. 在试算表「扩展程序 → Apps Script」，建立以下文件并贴上内容（文件名要完全一致，包括 `Viewver` 这个拼法）：`Code.gs`、`Cleanup.gs`、`Admin.html`、`Table.html`、`Viewver.html`、`TVBoard.html`。也可以用 clasp（见下方）。
2. 「部署 → 新增部署 → 网页应用」：执行身份选「我」，存取权限选「学校网域内的任何人」。
3. 拥有者在编辑器运行一次 `installMonthlyCleanupTrigger()`，建立每月自动清理。
4. 照 [Docs/上线检查清单.md](Docs/上线检查清单.md) 做上线后检查。

### 每次更新程序

1. 把新的代码放进 Apps Script：在本文件夹执行 `clasp push`，或在编辑器手动贴上。
2. 「部署 → 管理部署 → 选原本的部署 → ✏️ 编辑 → 版本选『新版本』→ 部署」。这样**网址不变**。

⚠️ 不要用「新增部署」更新，那会产生新网址，旧网址和电视看板还是跑旧代码。

### 用 clasp

- 项目文件夹里要有 `.clasp.json`，内容是 `{"scriptId":"<脚本 ID>"}`。脚本 ID 在 Apps Script 编辑器「⚙️ 项目设置」里。这个文件被 `.gitignore` 排除，重新从 GitHub 复制项目后要自己补回来。
- `clasp push` 会让线上项目**完全变成本地文件夹的样子**：线上有、本地没有的文件会被删掉。
- **不要用 `clasp pull`** 来「同步」，它会用线上的版本覆盖你本地还没推上去的修改。

## 维护函数（只有系统拥有者能运行）

在 Apps Script 编辑器上方选函数 → 「运行」。其他人从网页呼叫一律会被拒绝。

| 函数 | 用途 | 什么时候用 |
|---|---|---|
| `installMonthlyCleanupTrigger()` | 建立每月 1 号凌晨 3 点的自动清理 | 第一次部署时运行一次 |
| `uninstallMonthlyCleanupTrigger()` | 取消自动清理 | 不想自动清理时 |
| `clearConfigCache()` | 清除设定缓存 | 改了格子底色想马上看到效果 |
| `cleanupOldBookingMonthSheets()` | 立刻清理超过保留年限的借用记录 | 一般不需要 |
| `fixTimeColumnFormatting()` | 修复被表格误转成日期的时间资料 | 借用时间显示成一长串英文时 |
| `migrateAllSheetsToSplitTimeSchema()` | 旧结构月份表升级 | 只有从很旧的版本升级时 |

### 自动清理规则

在 `Cleanup.gs` 开头可以改：

- `CLEANUP_RETENTION_MONTHS = 3`：回收站和操作日志保留 3 个月。
- `CLEANUP_BOOKING_RETENTION_YEARS = 2`：借用记录保留**今年 + 去年**。例如 2029 年 1 月 1 日会删掉 2027 年整年的月份表。⚠️ 这是**永久删除**，不进回收站、无法恢复；需要留档请提前把那一年的工作表另存。设成 `0` 可以关闭。

## 常见问题

**矩阵总表、日历、电视看板都是空的？**
先确认那个月份的工作表（例如 `2026-10`）里真的有资料。页面能显示标题、图例、日期，只是格子是空的，通常就是那个月没有借用记录。

**管理端列表找不到某笔记录？**
列表预设只显示近期记录，把「资料范围」切成「全部记录」。

**改了单位或特殊状态的颜色，页面没变？**
颜色设定有 5 分钟缓存，等 5 分钟或请拥有者运行 `clearConfigCache()`。改文字（新增单位、场地、状态名称）会立刻生效。

**管理端显示「访问被拒绝」？**
你的账号不在《场地编号》表【管理员邮箱】里，请拥有者加上。

**更新程序后页面没变？**
是不是只存档或 `clasp push` 了，但没有在「管理部署」里把原本的部署改成「新版本」？另外，已经开着的分页要重新整理（Ctrl+F5）。

**`clasp push` 显示 `Project settings not found`？**
项目文件夹里缺 `.clasp.json`，见上方「用 clasp」。

**公告栏显示 `#ERROR!`？**
以前的版本在公告以 `- ` 开头时会被表格当成公式。现在已修正，在管理端把公告重新保存一次即可。
