# 场地借用系统 · 上线检查清单

> 最后整理：2026-10-05。部署、更新、上线后检查、定期维护时照着勾。操作细节见 [README](../README.md)。

## 1. 每次更新程序

- [ ] 本地项目文件夹有 `.clasp.json`（没有的话从 Apps Script「⚙️ 项目设置」复制脚本 ID 补上）
- [ ] 确认线上项目没有本地缺少、但还需要的文件（`clasp push` 会删掉它们）
- [ ] `clasp push`（或在编辑器手动贴上所有改动的文件）
- [ ] 「部署 → 管理部署 → 选**原本的**部署 → ✏️ 编辑 → 新版本 → 部署」（网址不变）
- [ ] 已经开着的页面按 Ctrl+F5 重新整理；电视看板最晚 6 小时内会自动换成新版
- [ ] 做下面第 3 节的上线后检查
- [ ] 把改动 commit 到 GitHub，并在 `CHANGELOG.md` 记一笔

## 2. 第一次部署（新的试算表）

- [ ] 《场地编号》表：A 栏课室编号、B 栏场地名称，以及「单位」「管理员邮箱」「管理员姓名」三个表头
- [ ] 行政单位格子上好底色
- [ ] （选填）假期三栏：假期设定(月) / 开始(日期) / 结束(日期)
- [ ] Apps Script 建好 `Code`、`Cleanup`、`Admin`、`Table`、`Viewver`、`TVBoard` 六个文件
- [ ] 新增部署：网页应用、执行身份「我」、存取「学校网域内的任何人」
- [ ] 拥有者在编辑器运行 `installMonthlyCleanupTrigger()`
- [ ] 第一次打开管理端后，《特殊状态》《公告栏》工作表自动出现

## 3. 上线后检查（每次更新后约 5 分钟）

管理端：

- [ ] 打开没有错误；「资料范围」下拉选单存在（代表是新版）
- [ ] 新增一笔测试借用（「填写人」留空）→ 出现绿色提示、填写人显示「姓名 (email)」
- [ ] 同场地同时段再提交一次 → 被挡下并说明冲突
- [ ] 结束时间早于开始时间 → 被挡下
- [ ] 修改那笔测试借用 → 成功，「🔗同批」仍可选到
- [ ] 新增一笔特殊状态，再取消 → 《特殊状态》表 A 栏的状态种类和颜色**还在**
- [ ] 删除测试借用 → 《已删除记录(回收站)》有这笔
- [ ] 公告栏输入以 `- ` 开头的条列并保存 → 矩阵总表显示正常（不是 `#ERROR!`）

公众页面：

- [ ] 矩阵总表：切到有资料的月份能看到格子颜色；点格子有明细；假期黄色、今天高亮正常
- [ ] 日历：周一开始、时间 24 小时制、事件有单位颜色
- [ ] 电视看板：三个场地、本周日期、图例、07:00 与 22:00 标签完整
- [ ] 用非管理员的学校账号打开管理端 → 显示「访问被拒绝」

## 4. 定期维护

| 时间 | 要做的事 |
|---|---|
| 每学年开始前 | 照新校历更新《场地编号》的假期设定 |
| 管理员异动时 | 在《场地编号》增删「管理员邮箱」，并填「管理员姓名」 |
| 每年 12 月 | 提醒：1 月 1 日的自动清理会**永久删除前年**的借用月份表（例：2028-01-01 删除 2026 年）。需要留档请先另存 |
| 每月 1 号后 | 偶尔看一下 Apps Script「执行」记录，确认 `cleanupOldTrashAndAuditLogs` 成功 |
| 改了格子颜色 | 等 5 分钟，或拥有者运行 `clearConfigCache()` |
