# 场地借用系统 · 需求规格

> 最后整理：2026-10-05。本文件记录系统**应该做什么**、以及使用方确认过的业务规则。怎么用见 [README](../README.md)，程序怎么实现见 [CLAUDE.md](../CLAUDE.md)，历次改动见 [CHANGELOG](../CHANGELOG.md)。
>
> 每条需求有编号（例如 `R-BK-03`），之后讨论或修改时可以直接引用。标「✅ 已确认」的是使用方明确拍板的规则，修改前要先跟使用方确认。

## 1. 背景与使用者

循人中学联课活动处用来登记、公布校内场地借用情况的系统。资料存在一份 Google 试算表「联课处场地系统-资料库」，程序是绑定在这份试算表上的 Google Apps Script 网页应用。

| 角色 | 能做什么 | 怎么认定 |
|---|---|---|
| 系统拥有者 | 一切操作，包括维护函数、部署 | 部署这个 Apps Script 的账号 |
| 管理员 | 新增/修改/删除借用记录、特殊状态、公告 | 《场地编号》表【管理员邮箱】列里有的账号 |
| 一般教职员/学生 | 浏览矩阵总表、日历、电视看板 | 学校网域（tsunjin.edu.my）的 Google 账号 |

## 2. 借用记录（管理端）

| 编号 | 需求 |
|---|---|
| R-BK-01 | 一次可以勾选**多个场地**提交；修改单笔记录时场地只能选一个。 |
| R-BK-02 | 场地可以用关键字搜寻，也可以按楼栋筛选：全部 / 大栋 / B栋 / C栋 / D栋 / F栋 / 其它。「大栋」= 大讲堂、大礼堂、伯才堂三个集会场所；其他按场地编号第一个字母分栋，对不上的归「其它」。 |
| R-BK-03 | 借用时间用 24 小时制选择开始、结束时间；**结束必须晚于开始**，跨午夜的活动拆成两笔。 |
| R-BK-04 | 可以借连续多天（开始日期 + 结束日期），结束日期不能早于开始日期。 |
| R-BK-05 | 可以只在特定星期几重复借用（例如 2 月 1 日至 3 月 1 日的每个星期六），此时必须填结束日期。 |
| R-BK-06 | **同场地同时段不可重复借用**：提交前检查整批「日期 × 场地」，任何一笔冲突就整批不写入，并说明跟哪一笔既有记录冲突。时段只是首尾相接（例如 09:00–11:00 与 11:00–12:00）不算冲突。 |
| R-BK-07 | 单次提交超过 50 笔要先确认；超过 200 笔直接拒绝（通常是日期打错）。 |
| R-BK-08 | 「填写人」可以留空，留空时自动带入「管理员姓名 (email)」，姓名来自《场地编号》表【管理员姓名】列；没填姓名就只带 email。✅ 已确认 |
| R-BK-09 | 「填写日期」自动为当天（以学校时区为准），使用者不能改；修改记录时更新为修改当天。 |
| R-BK-10 | 同一次提交产生的所有记录属于「同一批」，可以用「🔗同批」一键全部勾选；修改单笔记录后仍属于原本那一批。 |
| R-BK-11 | 删除单笔要确认；批量删除要手动输入要删除的笔数作为二次确认。 |
| R-BK-12 | 删除的记录先进《已删除记录(回收站)》；修改时旧版本也进回收站。 |
| R-BK-13 | 新增、修改、删除都记一笔《操作日志》，记录真实操作者的 Google 账号。 |
| R-BK-14 | 借用记录列表可以搜寻（活动/单位/填写人）、按场地、按日期筛选，分页每页 8 / 16 / 32 笔。 |
| R-BK-15 | 列表预设只读近期记录（3 个月前那个月起，含未来），可以切换成最近 12 个月或全部。 |
| R-BK-16 | 操作成功要有明确提示；载入失败要显示错误和重试按钮，不能卡在载入中。 |

## 3. 特殊状态

| 编号 | 需求 |
|---|---|
| R-SS-01 | 管理员可以把场地在某些日期标记成「维修」「考试场地」「不外借」等状态；状态种类不固定，在《特殊状态》表 A 列自行增加，格子底色就是该状态的显示颜色。 |
| R-SS-02 | 特殊状态**整天算**，不需要活动名称、单位、时间。 |
| R-SS-03 | 特殊状态**只做标记与显示，不阻挡借用**：同一场地同一天可以同时有借用记录和特殊状态。✅ 已确认（不要加「不外借时禁止提交」这类硬拦截） |
| R-SS-04 | 可以一次勾选多个场地 × 多个状态，日期规则（连续多天、按星期重复、上限）跟借用记录相同。 |
| R-SS-05 | 管理端有特殊状态清单，可以单笔或批量取消；取消不能影响《特殊状态》表 A 列的状态定义。 |
| R-SS-06 | 矩阵总表：彩色内框 + 右上角 🚧；日历：全天事件；电视看板：整栏底色 + 顶部标签。颜色一律用 A 列设定的颜色，没上色用橘色。 |

## 4. 颜色与图例

| 编号 | 需求 |
|---|---|
| R-CL-01 | 借用单位名称格式为「编号-名称」。编号以**数字**开头是学校行政单位（例如 01-校长室），以**字母**开头是学会团体（例如 A01 学长团）。 |
| R-CL-02 | 在《场地编号》表「单位」列手动上底色的行政单位，借用格子/事件用该颜色显示；学会团体不上色、不进图例。 |
| R-CL-03 | 图例顺序跟表格里的顺序一致。矩阵总表、日历、电视看板都显示「🏢 行政单位」「🚧 特殊状态」图例。 |
| R-CL-04 | 同一格有多个不同单位借用（时段不重叠）时，用斜向分段同时显示各单位颜色。 |

## 5. 假期

| 编号 | 需求 |
|---|---|
| R-HD-01 | 在《场地编号》表用【假期设定(月)】【开始(日期)】【结束(日期)】三列设定假期，一行一个月份的区间。✅ 已确认 |
| R-HD-02 | 设定**每年通用**（没有年份栏），换学年时由管理员照新校历修改。 |
| R-HD-03 | 跨月假期拆成两行；同一个月两段假期就多加一行同月份；某月没有假期则开始/结束留空。 |
| R-HD-04 | 矩阵总表、日历、电视看板把假期日期**整天填黄色底**；矩阵总表另有「🏖️ 假期」图例列出当月假期区段（DD/MM-DD/MM）。✅ 已确认 |
| R-HD-05 | 假期当天有借用的格子仍显示单位颜色；表头的「今天」标记优先于假期黄色；只有特殊状态的格子，特殊状态底色优先于假期黄色。 |

## 6. 公众页面

### 6.1 矩阵总表（`?page=table`）

| 编号 | 需求 |
|---|---|
| R-TB-01 | 场地为行、当月每一天为列；用中文的年/月下拉选单切换月份。 |
| R-TB-02 | 今天整列高亮，周末淡色，假期黄色；点有记录的格子弹出明细（特殊状态在最上方）。 |
| R-TB-03 | 表格约占 70%，右侧约 30% 是公告栏；窄屏时上下堆叠。 |
| R-TB-04 | 页面开着不关时，借用记录与公告每 5 分钟自动更新，并显示最后更新时间。 |

### 6.2 公告栏

| 编号 | 需求 |
|---|---|
| R-AN-01 | 公告内容存在《公告栏》工作表 A2，用 **Markdown** 语法撰写，也可以夹带原生 HTML（例如彩色文字）。✅ 已确认 |
| R-AN-02 | 管理端最下方有公告编辑区：大文本框 + 即时预览，存档后矩阵总表最多 5 分钟内更新；有未保存的修改时重新载入要先确认。 |
| R-AN-03 | 不使用 Google 文档当公告来源（Google 会不定期撤销文档授权，导致公告栏坏掉）。✅ 已确认 |
| R-AN-04 | B2 自动记录最后更新时间，矩阵总表显示「公告更新于 …」。 |

### 6.3 日历视图（`?page=view`）

| 编号 | 需求 |
|---|---|
| R-CV-01 | 月视图 / 周视图 / 明细表三种视图，中文介面，每周从星期一开始，时间 24 小时制。 |
| R-CV-02 | 点事件弹出明细；单位颜色、特殊状态全天事件、假期黄色底跟矩阵总表一致。 |

### 6.4 电视看板（`?page=tv`）

| 编号 | 需求 |
|---|---|
| R-TV-01 | 只显示大讲堂、大礼堂、伯才堂三个场地，三张表并排；日期为列（本周一到周日）、时间为行（07:00–22:00，每 30 分钟一格）。 |
| R-TV-02 | 标题显示本周日期区间，格式 `DD/MM/YYYY-DD/MM/YYYY`。✅ 已确认 |
| R-TV-03 | 场地上方显示「🏢 行政单位」「🚧 特殊状态」颜色图例，跟矩阵总表、日历一样是静态颜色说明。✅ 已确认 |
| R-TV-04 | 时间轴第一个（07:00）与最后一个（22:00）标签要完整显示，不能被裁掉一半。 |
| R-TV-05 | 今天那一列有红色「现在时间」线；假期黄色；特殊状态整栏底色 + 标签。 |
| R-TV-06 | 无人值守：资料每 5 分钟自动更新，失败时保留原画面并自动重试；每 6 小时整页重新载入，但要先确认网络与后端正常，避免卡在错误页。 |

## 7. 资料保留与清理

| 编号 | 需求 |
|---|---|
| R-CU-01 | 《已删除记录(回收站)》与《操作日志》保留最近 **3 个月**，每月自动清理一次。✅ 已确认 |
| R-CU-02 | 借用记录（月份工作表）保留**今年 + 去年**两个日历年；例如 2029 年 1 月 1 日删除 2027 年整年的月份表（「29 年才删除 27 年的记录」）。这是永久删除，不进回收站。✅ 已确认 |
| R-CU-03 | 清理由每月 1 号凌晨的定时触发器执行，只有系统拥有者能手动执行或修改。 |

## 8. 权限与安全

| 编号 | 需求 |
|---|---|
| R-SC-01 | 所有页面只开放给学校网域账号；管理端另外要求在管理员白名单内（拥有者永远有权限）。 |
| R-SC-02 | 所有写入操作在服务器端再次检查白名单，不能只靠页面挡。 |
| R-SC-03 | 迁移、修复、清理、安装触发器等维护功能只有系统拥有者能执行。 |
| R-SC-04 | 表格内容显示在网页上时必须防止被当成程序码执行（公告栏是管理员可信内容，例外）。 |
| R-SC-05 | 写入要能承受多位管理员同时操作，不能造成重复借用或删错资料。 |

## 9. 尚未处理 / 待讨论

- 电视看板的「今天」和红色时间线用电视本机的时区，电视时区设错会错位。
- 电视看板是固定像素版面，在很小的屏幕上需要卷动。
- 《场地编号》表的【状态】列（考场 / 维修 / 不外借）目前**程序没有读取**；特殊状态的种类以《特殊状态》表 A 列为准。要不要删掉这一列、或改成由它来定义，待使用方决定。
- 电视看板显示的三个场地写在程序里（`Code.gs` 与 `Admin.html` 各一份），要改需要改程序。
